## 사용 방법

### 1. PDF 또는 PPTX 열기

상단의 **열기** 버튼을 누르고 파일을 선택합니다.

또는 파일을 편집 영역으로 직접 드래그 앤 드롭할 수 있습니다.

### 2. 편집

상단 도구 모음에서 원하는 편집 도구를 선택합니다.

예를 들어:

1. `D`를 눌러 텍스트 도구 선택
2. 페이지를 클릭
3. 텍스트 입력
4. 개체 선택 도구로 위치와 크기 조절

### 3. 저장

**저장** 또는 **다른 이름으로 저장**을 선택합니다.

저장 형식은 다음 중 선택할 수 있습니다.

- PDF
- MPDF

편집을 계속할 예정이라면 MPDF, 최종 결과물을 공유할 예정이라면 PDF를 사용하는 것이 좋습니다.

## 기술 구성

Meow-PDF는 별도의 서버 없이 브라우저에서 동작하는 클라이언트 기반 웹 애플리케이션으로 구성되어 있습니다.

주요 라이브러리:

- [PDF.js](https://mozilla.github.io/pdf.js/) — PDF 렌더링 및 읽기
- [pdf-lib](https://pdf-lib.js.org/) — PDF 생성 및 저장
- [JSZip](https://stuk.github.io/jszip/) — MPDF 프로젝트 압축 / 해제
- Google Fonts — 한국어 글꼴 및 텍스트 렌더링

PPTX는 ZIP 기반의 Office Open XML 구조를 직접 읽어 슬라이드 XML, 레이아웃, 마스터, 테마 및 관련 리소스를 분석합니다.
