# Meow-PDF

설치 없이 브라우저에서 바로 쓰는 PDF 편집기입니다. PDF 속 글자를 눌러 고치고, 그리고, 합치고, 다른 형식으로 내보낼 수 있습니다. 컴퓨터와 휴대폰 모두에서 사용할 수 있습니다.

**소개 페이지: https://meow-pdf.com**

**바로 사용하기(편집 화면): https://meow-pdf.com/edit**

> 한동안 접속이 없었다면 첫 화면이 뜨기까지 수십 초가 걸릴 수 있습니다. 잠시 기다리면 열립니다.

## 시작하기

1. 위 주소로 접속합니다.
2. 화면에 PDF 파일을 끌어다 놓거나 "열기"를 눌러 파일을 선택합니다.
3. 필요한 도구로 편집합니다.
4. 저장 버튼으로 PDF를 내려받습니다.

PDF 외에 이미지, PPTX, HWP 파일도 열 수 있습니다.

## 할 수 있는 일

**편집**
- 글자 수정: PDF 안의 글자를 눌러 바로 고칠 수 있습니다. 글꼴, 크기, 굵게/기울임, 글자색, 배경색을 바꿀 수 있습니다.
- 텍스트 상자 추가(왼쪽 / 가운데 / 오른쪽 정렬 선택, 기본은 왼쪽), 펜, 형광펜, 선, 도형(사각형, 원, 별), 지우개
- 이미지 넣기
- 음성 녹음을 페이지에 넣기
- 실행 취소 / 다시 실행

**문서 관리**
- 여러 문서를 탭으로 열어 번갈아 작업
- 페이지 썸네일로 이동, 전체 페이지 관리
- PDF 합치기, 용량 줄이기(압축)
- 문서 안에서 검색, 책갈피, 인쇄, 현재 화면 캡처, 발표 모드
- 페이지 번역: 도구 모음 맨 오른쪽의 번역 버튼으로 지금 보고 있는 페이지만 번역합니다. 원문 / 전체 번역 / 마우스 오버 번역(글자에 마우스를 올리면 그 문단만 번역)을 고를 수 있고, 원본 언어는 자동으로 감지합니다. 번역할 언어는 기본이 한국어입니다. Chrome의 내장 번역을 쓰며, 지원하지 않는 브라우저에서는 서버 번역으로 대체됩니다.
- 번역 · 사전 (멀티작업): 멀티작업 탭의 + 메뉴 또는 가운데 번역 버튼으로 엽니다. 글을 번역하고, 단어를 찾으면 Wiktionary의 뜻을 원하는 언어로 함께 보여줍니다. 결과는 복사, 노트에 추가, 페이지에 삽입할 수 있고 파파고 · 구글 번역 · DeepL · 네이버 사전 바로가기가 있습니다.
- 모바일 열기 모드: 모바일에서 파일을 열 때 보기(읽기 전용) / 간편 수정(글자 수정 제외) / 기본(모든 기능) 중 고릅니다. 더보기 메뉴의 "보기 · 편집 모드"에서 바꿀 수 있습니다.
- 자간: 텍스트 옵션에서 -10% ~ 50%로 조절합니다. PDF 글자를 클릭해 수정하면 원본의 자간을 읽어 같은 간격으로 반영합니다.
- 편집기 언어: 설정 > 화면 · 레이아웃 > 언어에서 한국어 / English / 日本語 / 中文으로 바꿀 수 있습니다. 선택은 이 브라우저에 저장됩니다.
- PDF로 저장, 편집 상태를 유지하는 MPDF로 저장, PPTX로 내보내기(페이지 한 장이 슬라이드 한 장)

**설정 (오른쪽 위 톱니바퀴, Ctrl+,)**
- 단축키 사용자 지정: 주요 기능의 단축키를 직접 바꾸고, 겹치는 키는 안내를 받아 교체하고, 기본값으로 되돌릴 수 있습니다. 기본 도구 단축키는 키보드 줄 순서예요 — Q W E R(강조표시 · 그리기 · 직선 · 지우개), A S D F(도형 · 텍스트 · 링크 · 표), Z X C V(영역 · 이미지 · 메모 · 음성).
- 도구 모음 위치: 상단 정렬 또는 좌측 정렬을 선택할 수 있습니다. 좌측 정렬에서는 메모 · 음성 · 캡처 · 인쇄 · 발표 · 번역이 ‘더보기’ 도구 안에 모여 있습니다.
- 정보 · 고객센터: 버전과 업데이트 내역을 확인하고, 불편사항이나 의견을 바로 보낼 수 있습니다.
- 테마 스토어: 넓은 창에서 실제 화면 모양 미리보기를 보며 테마를 고릅니다. 무료(어두운 · 밝은 · 한국 · 일본 · 커피 · 키위 다크), 프리미엄, 기간 한정(공포: 매년 9월 1일 ~ 11월 30일만 무료, 그 밖에는 프리미엄), 가장 최근에 나온 테마의 NEW 딱지, 나만의 커스텀 테마를 한곳에서 볼 수 있습니다.
- 화면 밝기 조절, 라이트 / 다크 테마 전환(어두운 화면이 기본)

## 휴대폰에서 쓰기

화면이 작아지면 자동으로 모바일 화면으로 바뀝니다.

- 한 화면에 한 페이지가 보이고, 꼭 필요한 도구만 남습니다.
- 도구는 위쪽에, 페이지 목록과 이동 버튼은 아래쪽에 있습니다.
- PDF 글자를 한 번 누르면 바로 수정할 수 있습니다.
- 두 손가락으로 벌리거나 모아 확대·축소하고, 그대로 움직여 화면을 옮길 수 있습니다. 어떤 도구를 쓰고 있어도 됩니다.
- 손가락 하나로 화면을 좌우로 끌면 페이지가 넘어갑니다.
- 펜 같은 그리기 도구를 쓰는 중에는 두 손가락으로 좌우로 밀어 페이지를 넘깁니다.
- 확대한 상태에서는 끌어서 화면을 옮기고, 맞춤 크기로 돌아오면 다시 페이지 넘기기가 됩니다.
- 가로로 돌리면 페이지 패널이 화면 왼쪽에 자동으로 나타납니다.
- 오른쪽 위 메뉴(점 세 개)에서 열기, 새 문서, 다른 이름으로 저장, 검색, 책갈피, 인쇄, 설정, 테마 전환을 쓸 수 있습니다.

## 로그인과 프리미엄

기본 편집 기능은 무료입니다. 전체 페이지 관리, 압축, PPTX 내보내기, 음성 녹음, 메모, 번역(페이지 번역 · 번역 · 사전) 같은 일부 기능은 프리미엄에서 사용할 수 있습니다.

프리미엄은 아래 중 하나로 이용할 수 있습니다.

| 방법 | 설명 |
| --- | --- |
| 대학생 인증 | 학교 이메일(`.ac.kr`, `.edu`)로 인증번호 로그인 |
| 이용 키 | 받은 키를 계정 창의 "이용 키"에 입력. 발급일로부터 3개월간 이용 |
| 결제 | 계정 창에서 **월간 구독 1,200원/월** 또는 **연간 구독 10,500원/년** 선택 (토스 자동결제). 결제일마다 자동 결제 · 계정 창에서 언제든 해지(해지해도 낸 기간은 유지) · 정기결제 실패 시 하루 간격 3회 재시도 · 이용 키는 발급일로부터 3개월 · 환불은 7일 이내(단순 변심 불가, 시스템 오류·미제공 가능) |

가입할 때 닉네임 · 아이디(중복 불가) · 비밀번호 · 이메일을 입력하고, 메일로 받은 인증번호(6자리)로 확인합니다. 이후에는 아이디와 비밀번호만으로 로그인합니다(이메일로도 로그인 가능). 로그인 후에는 현재 비밀번호를 확인하고 비밀번호를 바꿀 수 있으며, 로그인 전에는 등록된 이메일로 받은 인증번호로 비밀번호를 재설정합니다. 프로필 사진과 닉네임은 계정 창에서 바꿉니다.

> 아이디 로그인과 프로필 사진을 쓰려면 Supabase SQL Editor 에서 `supabase.sql` 의 **5번(아이디 · 닉네임 · 프로필 사진)** 을 실행하고, 결제 서버를 새 `server.js` 로 다시 배포해야 합니다.

## 알아두세요

- 파일은 브라우저에서 처리됩니다. 편집 중인 PDF가 서버에 올라가지 않습니다.
- 암호가 걸린 PDF와 배포용 HWP는 열 수 없습니다.
- 예전 `.ppt` 형식은 PowerPoint에서 `.pptx`로 저장한 뒤 열어 주세요.
- 음성 녹음은 마이크 권한 허용이 필요하고, Chrome이나 Edge에서 가장 잘 동작합니다.
- 저장하지 않고 창을 닫으면 편집 내용이 사라질 수 있으니, 작업 후에는 꼭 저장해 주세요.

## 문의

문제가 있거나 키가 필요하면 개발자에게 연락해 주세요: contact@meow-pdf.com

- 멀티작업의 계산기: 사칙연산 · 괄호 · % · 제곱 · 제곱근을 키보드로 입력하고, 결과를 복사하거나 노트/페이지에 넣을 수 있어요.
- 줌 바는 왼쪽 점 손잡이를 끌어 가장자리로 옮길 수 있어요(좌우에서는 세로로 바뀌며, 더블클릭하면 원위치).
- 영역 지정(R): 그림판처럼 사각형 또는 자유 선택으로 영역을 지정한 뒤 안쪽을 끌면, 펜 그림·도형의 그 부분만 잘라 옮길 수 있어요. 잘라내기·복사·붙여넣기·삭제와 영역 이미지 복사·저장, 글자 복사도 지원해요.
- 헤더의 전체화면 버튼으로 화면을 가득 채워 볼 수 있어요(모바일은 ⋮ 메뉴).
- 형광펜은 글자를 흐리게 하지 않아요(곱하기 방식, 저장 PDF 포함). 글자 위에 칠하면 글자 줄에 맞는 띠로 자동 정리되며, 옵션에서 '자유'로 끌 수 있어요.
- 레이어 방식: 설정 또는 레이어 패널에서 ‘자동’(개체마다)과 ‘수동’(그림판처럼 레이어를 직접 추가·이름 변경·순서 변경·숨김·잠금·병합)을 고를 수 있어요.
- 페이지 보기: 설정에서 PC는 ‘연속 스크롤 / 한 페이지씩 보기’, 모바일은 ‘한 페이지씩(좌우 넘기기) / 세로로 넘기기’를 고를 수 있어요.

- 상단 헤더에 개발자 콘솔 버튼(`</>`)이 생겼어요. 개발자 콘솔은 프리미엄 사용자 전용이에요. 모바일에서는 더보기(⋮) 메뉴에 있어요.
- 모바일 설정창의 상단 메뉴를 아이콘 위주로 바꿔 잘리지 않게 했어요.

- 핑크세상 테마(연한 핑크)를 추가했어요. 설정 > 테마 또는 콘솔 `set theme 4` / `set theme pinktheme`.
- 빠른 콘솔: 상단 `</>` 버튼이나 `/` 키(프리미엄)를 누르면 작은 입력 칸이 열려요. Enter로 실행하면 결과가 알림으로 뜨고 닫혀요. Esc 또는 ✕로도 닫을 수 있고, 결과가 길면 전체 콘솔로 보여줘요.

> 3. 편집기는 Supabase 를 직접 부르므로 결제 서버(Render) 재배포는 필요 없어요.
>
> 동작 방식 · 제한
> - 문서 원본(PDF · 그림 · 음성)은 처음 한 번만 Storage 에 올리고, 편집 내용은 개체 단위로 실시간 채널로 주고받아요. 늦게 들어온 사람은 `state.json`(페이지 · 개체 목록)을 받아서 시작해요.
> - 같은 개체를 두 사람이 동시에 고치면 나중 변경이 남아요(램포트 시계). 실행 취소는 내가 한 변경만 되돌려요.
> - 프로젝트 만들기 · 공개 범위 바꾸기는 프리미엄, 참여는 로그인만 하면 돼요. 참여도 프리미엄으로 막으려면 SQL 의 `share_join` · `share_join_code` 에서 `meow_me(false)` 를 `meow_me()` 로 바꾸세요.
> - ‘모두 공개’ 목록은 아직 준비 중이에요. 지금은 모두 공개로 두어도 목록에는 안 보이고 코드로만 들어올 수 있어요.
> - 방장이 공유 탭을 닫아도 프로젝트는 계속 열려 있어요(공유작업 패널 › 내 프로젝트에서 다시 열기). 완전히 끝내려면 프로젝트 관리 › 공유 종료.
> - 관전자 제한은 화면(편집 막기 · 받는 쪽에서 관전자 변경 무시)으로 지켜요. Realtime 정책은 ‘참여자인지’까지만 확인해요.
