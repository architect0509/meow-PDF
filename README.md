# 🐾 Meow-pdf.com

> **Meow-pdf.com**은 모바일과 데스크톱 환경 모두에서 PDF 문서 및 텍스트 레이아웃을 직관적으로 관리할 수 있는 웹 기반 뷰어 및 편집 플랫폼입니다.

---

## 주요 기능

- **직관적인 텍스트 편집**: 문서 내 텍스트를 터치나 클릭만으로 바로 수정할 수 있습니다.
- **모바일 반응형 디자인**: 화면 크기에 맞춰 자동으로 레이아웃이 최적화됩니다.
- **터치 & 제스처 지원**:
  - 모바일 환경에서 화면을 스와이프하거나 드래그하여 페이지를 넘길 수 있습니다.
  - 두 손가락(Pinch-to-Zoom)을 이용해 화면 확대 및 축소가 가능합니다.
- **모바일 UI/UX 최적화**:
  - 부가 기능(레이어, 노트, 멀티작업 등)을 가리고 최소한의 핵심 기능만 남깁니다.
  - 페이지 패널을 하단으로 배치하여 조작성을 높였습니다.
  - 상단 편집 버튼과 계정 버튼(저장 버튼 왼쪽)을 정돈하여 배치했습니다.
- **스마트 옵션바 (Optbar)**: 텍스트 선택 시 관련 도구가 화면을 벗어나지 않도록 두 줄로 정렬되며, 옵션바 표시에 따른 페이지 레이아웃 재조정이 발생하지 않습니다.

## 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Responsive Design, CSS Flexbox/Grid
- **Interactions**: Touch Events, Gesture Handling
