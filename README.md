# Meow-PDF

설치 없이 브라우저에서 바로 쓰는 PDF 편집기입니다. PDF 속 글자를 눌러 고치고, 그리고, 합치고, 다른 형식으로 내보낼 수 있습니다. 컴퓨터와 휴대폰 모두에서 사용할 수 있습니다.

**소개 페이지: https://meow-pdf.com**

**바로 사용하기(편집 화면): https://meow-pdf.com/edit**

> 한동안 접속이 없었다면 첫 화면이 뜨기까지 수십 초가 걸릴 수 있습니다. 잠시 기다리면 열립니다.

## 시작하기

1. 위 주소로 접속합니다.
2. 화면에 PDF 파일을 끌어다 놓거나 "열기"를 눌러 파일을 선택합니다.
3. 필요한 도구로 편집합니다.
4. 저장 버튼으로 PDF를 내려받습니다.

PDF 외에 이미지, PPTX, HWP 파일도 열 수 있습니다.

## 할 수 있는 일

**편집**
- 글자 수정: PDF 안의 글자를 눌러 바로 고칠 수 있습니다. 글꼴, 크기, 굵게/기울임, 글자색, 배경색을 바꿀 수 있습니다.
- 텍스트 상자 추가(왼쪽 / 가운데 / 오른쪽 정렬 선택, 기본은 왼쪽), 펜(종류: 붓(기본, 필압 없음) · 펜(필압과 속도로 굵기) · 스프레이, 획 보정 · 손떨림 보정 끔/약/중/강, 기본: 둘 다 끄기), 형광펜(굵기 · 불투명 10~100%), 선, 도형(사각형, 둥근 사각형 — 위쪽 노란 점을 끌어 모서리 조절, 원, 별, 화살표, 자유형: 도형 · 자유 곡선), 지우개
- 이미지 넣기
- 음성 넣기: 음성 도구의 드롭다운에서 음성 녹음 또는 MP3 파일 넣기(최대 30MB)를 골라 페이지에 넣기
- 실행 취소 / 다시 실행
- 자동 저장(기본: 꺼짐): 설정 › 화면 · 레이아웃 › 자동 저장에서 1 · 3 · 5 · 10분 간격으로 켜기 — 열었거나 저장한 파일에는 바로 덮어쓰고, 저장할 파일이 없으면 이 기기에 복구용으로 보관했다가 다음에 열 때 되살리기
- 그룹화: Ctrl · Shift로 여러 개체를 고른 뒤 우클릭 › 그룹화(Ctrl+G) · 그룹화 해제(Ctrl+Shift+G) — 묶인 개체는 하나만 눌러도 함께 선택 · 이동 · 크기 조절
- 빈 문서: 가로 · 세로 · 커스텀(가로 · 세로 mm 직접 입력) 중에서 골라 만들기
- PC: 헤더 · 탭바 접기 / 펼치기 (탭바 오른쪽 끝 버튼 · Ctrl+Shift+H), PC 프로그램은 F11로 전체화면
- 인쇄: 헤더의 인쇄 버튼(Ctrl+P) · 썸네일의 ‘이 페이지 인쇄’ — 복사본 수 · 프린터 · 페이지 범위 · 방향 · 용지 · 컬러/흑백 · 배율 · 여백 · 미리 보기
- 나만의 테마 배경 이미지: 시스템 그림 또는 직접 올린 그림, 반복 / 시스템 색 채우기, 크기 · 위치 조절과 미리 보기
- 개체 선택 방식: 바운딩 박스(기본 · 점을 끌어 크기 · 위쪽 손잡이로 회전) / 기즈모(PC)
- 옵션바 기울기: 도형 · 이미지 · 글자 · 표의 회전 각도를 숫자로 입력 (0–360°)
- 스마트 안내선: 옮기거나 크기를 바꿀 때 다른 개체 · 페이지의 양 끝과 가운데가 맞으면 빨간 점선으로 알려 주고 딱 맞춤 (Alt: 끄기)
- (PC 기즈모 모드) 유니티식 변형 도구: 화면 이동(Q) · 이동(W) · 회전(E) · 크기 조절(R) · 사각형 변형(T) · 통합 변형(Y)로 이미지를 옮기고 돌리고 늘리기

**문서 관리**
- 여러 문서를 탭으로 열어 번갈아 작업 (탭 너비는 모두 같고, 많아지면 좌우 화살표 · 마우스 휠로 탭 줄 이동)
- 노트: MD · TXT · 그림판(펜 · 형광펜 · 직선 · 지우개 · 도형 · 텍스트 상자 · 표, Ctrl+휠로 확대 · 축소) — 그림판은 PNG로 내보내기 · 현재 탭에 붙여넣기 · 새 탭으로 열기
- 페이지 썸네일로 이동, 전체 페이지 관리
- 페이지 패널 우클릭: 배경 색 바꾸기, 그룹에 넣기 · 그룹에서 빼기 / 그룹 설정(톱니 · 우클릭): 이름 바꾸기 · 폴더 색, 페이지 패널 맨 위에 고정(패널에서만, 문서 순서는 그대로)
- 최근에 연 파일: 메인 탭의 ‘최근에 연 파일’에서 다시 열기 · 기록에서 삭제 · (PC 프로그램) 파일 위치 열기
- PDF 합치기(PNG도 함께), 용량 줄이기(압축), 페이지 · 레이어 복제
- 문서 안에서 검색, 책갈피, 인쇄, 현재 화면 캡처, 발표 모드
- 페이지 번역: 도구 모음 맨 오른쪽의 번역 버튼으로 지금 보고 있는 페이지만 번역합니다. 원문 / 전체 번역 / 마우스 오버 번역(글자에 마우스를 올리면 그 문단만 번역)을 고를 수 있고, 원본 언어는 자동으로 감지합니다. 번역할 언어는 기본이 한국어입니다. Chrome의 내장 번역을 쓰며, 지원하지 않는 브라우저에서는 서버 번역으로 대체됩니다.
- 번역 · 사전 (멀티작업): 멀티작업 탭의 + 메뉴 또는 가운데 번역 버튼으로 엽니다. 글을 번역하고, 단어를 찾으면 Wiktionary의 뜻을 원하는 언어로 함께 보여줍니다. 결과는 복사, 노트에 추가, 페이지에 삽입할 수 있고 파파고 · 구글 번역 · DeepL · 네이버 사전 바로가기가 있습니다.
- 모바일 열기 모드: 모바일에서 파일을 열 때 보기(읽기 전용) / 간편 수정(글자 수정 제외) / 기본(모든 기능) 중 고릅니다. 더보기 메뉴의 "보기 · 편집 모드"에서 바꿀 수 있습니다.
- 자간: 텍스트 옵션에서 -10% ~ 50%로 조절합니다. PDF 글자를 클릭해 수정하면 원본의 자간을 읽어 같은 간격으로 반영합니다.
- 편집기 언어: 설정 > 화면 · 레이아웃 > 언어에서 한국어 / English / 日本語 / 中文으로 바꿀 수 있습니다. 선택은 이 브라우저에 저장됩니다.
- PDF로 저장, 편집 상태를 유지하는 MPDF로 저장, PPTX로 내보내기(페이지 한 장이 슬라이드 한 장)

**설정 (오른쪽 위 톱니바퀴, Ctrl+,)**
- 단축키 사용자 지정: 주요 기능의 단축키를 직접 바꾸고, 겹치는 키는 안내를 받아 교체하고, 기본값으로 되돌릴 수 있습니다. 기본 도구 단축키는 키보드 줄 순서예요 — Q W E R(강조표시 · 그리기 · 직선 · 지우개), A S D F(도형 · 텍스트 · 링크 · 표), Z X C V(영역 · 이미지 · 메모 · 음성).
- 도구 모음 위치: 상단 정렬(기본) 또는 좌측 정렬을 선택할 수 있습니다. 좌측 정렬에서는 메모 · 음성 · 캡처 · 인쇄 · 발표 · 번역이 ‘더보기’ 도구 안에 모여 있습니다. 상단 정렬에서 창이 좁으면 다 들어가지 않는 오른쪽 도구가 ‘더보기’ 안으로 들어갑니다.
- 정보 · 고객센터: 버전과 업데이트 내역을 확인하고, 불편사항이나 의견을 바로 보낼 수 있습니다.
- 테마 스토어: 넓은 창에서 실제 화면 모양 미리보기를 보며 테마를 고릅니다. 무료(어두운 · 밝은 · 한국 · 일본 · 커피 · 키위 다크), 프리미엄, 기간 한정(공포 · 아날로그 호러: 매년 9월 1일 ~ 11월 30일만 무료, 그 밖에는 프리미엄), 가장 최근에 나온 테마의 NEW 딱지, 나만의 커스텀 테마를 한곳에서 볼 수 있습니다. 테마 카드의 ☆로 즐겨찾기에 담고, 왼쪽 메뉴의 ‘최근 사용’(최근 6개) · ‘즐겨찾기’에서 모아 봅니다.
- 화면 밝기 조절, 라이트 / 다크 테마 전환(어두운 화면이 기본)

## PC 프로그램 (Windows · macOS · Linux)

소개 페이지(PC)의 **PC 프로그램** 영역에서 내려받습니다. 설치하면 소개 화면 없이 바로 편집 화면이 열리고, 인터넷이 없어도 열립니다.

- Windows 10 · 11 (64비트): `Meow-PDF-Setup.exe`
- macOS 11 이상 (Apple 실리콘 · 인텔): `Meow-PDF-mac.dmg`
- Linux 64비트: `Meow-PDF-linux.AppImage` (실행 권한을 준 뒤 실행)
- 새 버전이 나오면 알림(버전마다 한 번)과 오른쪽 아래 창으로 알려 주고, 설정 › 버전 정보에서 업데이트할 수 있습니다. Windows · Linux(AppImage)는 프로그램이 내려받아 다시 시작하며 설치하고, macOS는 다운로드 페이지를 엽니다.
- 설치하면 PDF · MPDF 파일에 Meow-PDF 파일 아이콘이 붙고, 파일을 두 번 누르면 Meow-PDF에서 열립니다. (Windows는 기본 앱을 Meow-PDF로 바꿔야 PDF 아이콘이 바뀝니다 — 프로그램 오른쪽 아래 ‘기본 연결 프로그램으로 설정해보세요!’ 창의 설정하기로 바꿀 수 있어요)
- 처음 실행할 때 보안 경고가 뜨면 Windows는 ‘추가 정보 → 실행’, macOS는 Finder에서 앱을 우클릭한 뒤 ‘열기’를 누릅니다. (코드 서명 인증서를 쓰면 경고 없이 열립니다)

### 새 버전 내보내기 (개발자용)

1. `public/edit.html` 의 `APP_VERSION` 과 `CHANGELOG` 를 올립니다.
2. `node scripts/make-version-json.js` 를 실행해 `public/version.json` 을 새로 만듭니다. (프로그램은 이 파일로 새 버전과 바뀐 내용을 알려 줍니다)
3. 커밋하고 같은 버전으로 태그를 올립니다: `git tag v1.0.1 && git push origin v1.0.1`
4. GitHub Actions(`.github/workflows/desktop.yml` — 처음 한 번 `desktop/ci/desktop.yml` 을 이 위치로 옮겨 주세요)가 Windows · macOS · Linux 설치 파일을 만들어 GitHub Releases에 올립니다. 사이트의 `/download/windows` · `/download/mac` · `/download/linux` 는 최신 릴리스의 설치 파일로 연결됩니다(`vercel.json`).
5. 프로그램 코드는 `desktop/` 폴더에 있습니다. 직접 실행: `cd desktop && npm install && npm start`

## 휴대폰에서 쓰기

화면이 작아지면 자동으로 모바일 화면으로 바뀝니다.

- 한 화면에 한 페이지가 보이고, 꼭 필요한 도구만 남습니다.
- 도구는 위쪽에, 페이지 목록과 이동 버튼은 아래쪽에 있습니다.
- PDF 글자를 한 번 누르면 바로 수정할 수 있습니다.
- 두 손가락으로 벌리거나 모아 확대·축소하고, 그대로 움직여 화면을 옮길 수 있습니다. 어떤 도구를 쓰고 있어도 됩니다.
- 손가락 하나로 화면을 좌우로 끌면 페이지가 넘어갑니다.
- 펜 같은 그리기 도구를 쓰는 중에는 두 손가락으로 좌우로 밀어 페이지를 넘깁니다.
- 확대한 상태에서는 끌어서 화면을 옮기고, 화면 왼쪽 · 오른쪽 끝에 닿은 뒤 한 번 더 밀면 이전 · 다음 페이지로 넘어갑니다. 맞춤 크기로 돌아오면 다시 바로 페이지 넘기기가 됩니다.
- 가로로 돌리면 페이지 패널이 화면 왼쪽에 자동으로 나타납니다.
- 오른쪽 위 메뉴(점 세 개)에서 열기, 새 문서, 다른 이름으로 저장, 검색, 책갈피, 인쇄, 설정, 테마 전환을 쓸 수 있습니다.

## 로그인과 프리미엄

기본 편집 기능은 무료입니다. 전체 페이지 관리, 압축, PPTX 내보내기, 음성 녹음, 메모, 모자이크, 번역(페이지 번역 · 번역 · 사전) 같은 일부 기능은 프리미엄에서 사용할 수 있습니다.

프리미엄은 아래 중 하나로 이용할 수 있습니다.

| 방법 | 설명 |
| --- | --- |
| 1개월 무료 체험 | 계정당 한 번 · 카드 등록 없이 · 끝나도 자동결제 없음. 헤더의 ‘1개월 무료’ 버튼 · 시작 화면 · 계정 창 · 소개 페이지 요금 안내(`/edit?trial=1`)에서 시작 |
| 대학생 인증 | 학교 이메일(`.ac.kr`, `.edu`)로 인증번호 로그인 |
| 이용 키 | 받은 키를 계정 창의 "이용 키"에 입력. 발급일로부터 3개월간 이용 |
| 결제 | 계정 창에서 **1개월 이용권 1,200원** 또는 **1년 이용권 10,500원** 선택 (토스 결제창, 한 번 결제). 자동결제 없음 · 이용 기간이 남아 있으면 그 뒤에 이어서 연장 · 3일 이내로 남으면 앱에서 연장 알림 · 이용 키는 발급일로부터 3개월 · 환불은 7일 이내(단순 변심 불가, 시스템 오류·미제공 가능) |

가입할 때 닉네임 · 아이디(중복 불가) · 비밀번호 · 이메일을 입력하고, 메일로 받은 인증번호(6자리)로 확인합니다. 이후에는 아이디와 비밀번호만으로 로그인합니다(이메일로도 로그인 가능). 로그인 후에는 현재 비밀번호를 확인하고 비밀번호를 바꿀 수 있으며, 로그인 전에는 등록된 이메일로 받은 인증번호로 비밀번호를 재설정합니다. 프로필 사진과 닉네임은 계정 창에서 바꿉니다.

Google 계정 · 네이버 계정으로도 로그인할 수 있습니다(처음이면 그 계정으로 바로 가입, 아이디는 계정 창 › 프로필에서 정하기).

> **v1.1.1 서버 설정 (소셜 로그인 · 무료 체험)**
> - **Google 로그인**: Supabase › Authentication › Providers › Google 을 켜고 Google Cloud 의 OAuth 클라이언트 ID · 시크릿을 넣습니다. Authentication › URL Configuration › Redirect URLs 에 `https://www.meow-pdf.com/auth-callback` (개발 중이면 `http://localhost:3000/auth-callback` 도) 를 추가합니다. 켜지지 않았으면 편집기가 ‘아직 준비되지 않았어요’라고 안내합니다.
> - **네이버 로그인**: 네이버 개발자센터 › 애플리케이션 등록(네이버 로그인, 이메일 제공 필수) › Callback URL 에 `<PUBLIC_BASE_URL>/auth/naver/callback` 을 넣고, 결제 서버 `.env` 에 `NAVER_CLIENT_ID` · `NAVER_CLIENT_SECRET` 을 추가한 뒤 새 `server.js` 로 다시 배포합니다. 같은 이메일로 이미 가입한 계정은 네이버 메일(@naver.com)이거나 전에 네이버로 연결한 계정일 때만 이어서 로그인합니다.
> - **1개월 무료 체험**: 새 `server.js` 의 `POST /api/trial/start` 가 계정(auth.users)의 `app_metadata.trial_used_at` 에 한 번만 기록하고 `users_profile.premium_until` 을 1개월 늘립니다(`premium_source = 'trial'`). DB 표를 새로 만들 필요는 없습니다.
> - **PC 프로그램**: 로그인 작은 창을 앱 안에서 열도록 `desktop/main.js` 가 바뀌어서 새 설치 파일(v1.1.1)을 배포해야 합니다. 예전 PC 프로그램에서는 로그인 창이 기본 브라우저로 열릴 수 있습니다.

> 아이디 로그인과 프로필 사진을 쓰려면 Supabase SQL Editor 에서 `supabase.sql` 의 **5번(아이디 · 닉네임 · 프로필 사진)** 을 실행하고, 결제 서버를 새 `server.js` 로 다시 배포해야 합니다.

## 알아두세요

> 2. Supabase 대시보드 → Realtime 이 켜져 있는지 확인하세요. 공유작업은 비공개 채널(`share:<프로젝트 id>`)을 쓰고, 참여자만 들어올 수 있도록 `realtime.messages` 정책으로 막아요. (Realtime › Settings 의 ‘Allow public access’를 끄면 공개 채널은 막히고 비공개 채널만 쓸 수 있어요. 켜 두어도 공유작업은 동작해요.)
> 3. 편집기는 Supabase 를 직접 부르므로 결제 서버(Render) 재배포는 필요 없어요.
>
> 동작 방식 · 제한
> - 문서 원본(PDF · 그림 · 음성)은 처음 한 번만 Storage 에 올리고, 편집 내용은 개체 단위로 실시간 채널로 주고받아요. 늦게 들어온 사람은 `state.json`(페이지 · 개체 목록)을 받아서 시작해요.
> - 같은 개체를 두 사람이 동시에 고치면 나중 변경이 남아요(램포트 시계). 실행 취소는 내가 한 변경만 되돌려요.
> - 프로젝트 만들기 · 공개 범위 바꾸기는 프리미엄, 참여는 로그인만 하면 돼요. 참여도 프리미엄으로 막으려면 SQL 의 `share_join` · `share_join_code` 에서 `meow_me(false)` 를 `meow_me()` 로 바꾸세요.
> - ‘모두 공개’ 목록은 아직 준비 중이에요. 지금은 모두 공개로 두어도 목록에는 안 보이고 코드로만 들어올 수 있어요.
> - 방장이 공유 탭을 닫아도 프로젝트는 계속 열려 있어요(공유작업 패널 › 내 프로젝트에서 다시 열기). 완전히 끝내려면 프로젝트 관리 › 공유 종료.
> - 관전자 제한은 화면(편집 막기 · 받는 쪽에서 관전자 변경 무시)으로 지켜요. Realtime 정책은 ‘참여자인지’까지만 확인해요.
