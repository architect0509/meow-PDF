어디서나

인터넷이 끊겨도, 휴대폰에서도
작업은 그대로 이어집니다

Meow-PDF는 브라우저 안에서 돌아가는 문서 편집기입니다. 문서는 서버로 보내지 않고 내 기기에서 열고 고치고 저장합니다.

온라인일 때

로그인, 실시간 공유작업과 채팅, 친구 · 메일 · 알림, 페이지 번역처럼 연결이 필요한 기능까지 모두 씁니다.

오프라인일 때

한 번 열어 둔 편집기는 연결 없이도 열립니다. 파일 열기, 글자 수정, 그리기, 페이지 정리, PDF · MPDF 저장은 그대로 됩니다.

휴대폰 · 태블릿에서

컴퓨터와 같은 편집기가 작은 화면에 맞춰 바뀝니다. 손가락으로 확대하고 넘기고, 펜으로 바로 표시합니다.

기능

문서 작업에 필요한 모든 것을 한곳에

PDF 편집부터 공동 작업, 형식 변환까지. 여러 프로그램을 오가지 않아도 됩니다.

글자 바로 수정

PDF 안의 글자를 눌러 원래 글꼴 · 크기 · 띄어쓰기 그대로 고칩니다. 스캔본이나 이미지 속 글자도 디지털화로 고칠 수 있는 글자로 바꿉니다.

실시간 공유작업

고유 코드나 링크 하나로 여러 사람이 같은 문서를 함께 고칩니다. 서로의 마우스 위치와 보고 있는 페이지가 프로필 사진으로 보이고, 채팅으로 바로 이야기합니다.

오프라인에서도

한 번 열어 둔 편집기는 인터넷이 끊겨도 그대로 열립니다. 파일 열기 · 편집 · 저장은 모두 내 기기 안에서 처리되어 비행기 · 지하철에서도 작업을 이어갑니다.

그리기 · 도형 · 표

펜, 형광펜, 직선, 화살표, 도형, 표, 이미지, 메모, 음성 녹음까지. 형광펜은 글자를 가리지 않고 글줄에 맞춰 칠해지고, 표는 칸마다 정렬과 글자 크기를 정합니다.

문서 관리

여러 문서를 탭으로 열고, 전체 페이지 관리에서 회전 · 순서 · 그룹을 정리하고, PDF를 합치고, 용량을 줄입니다.

원하는 형식으로

PDF와 편집 상태를 그대로 담는 MPDF로 저장하고, PPTX · Word(.docx) · 한글(.hwpx) · PNG로 내보냅니다.

멀티작업

문서를 보면서 옆 패널에서 다른 파일, 웹페이지, 계산기, 번역 · 사전, 노트를 함께 엽니다.

친구 · 메일 · 알림

아이디로 친구를 추가하고 메일을 주고받습니다. 친구가 진행 중인 공유작업에 바로 참여할 수 있습니다.

영역 지정과 레이어

영역을 사각형이나 자유 형태로 지정해 그림과 도형의 일부를 오리고 옮깁니다. 자동 레이어와 그림판식 수동 레이어를 고를 수 있습니다.

발표 모드

전체 화면으로 발표하며 펜과 형광펜으로 표시하고, 레이저 포인터는 지나간 자리에 잔상을 남깁니다.

내 방식대로

테마 스토어에서 분위기를 바꾸고, 단축키와 도구 모음 위치를 정하고, 39가지 글꼴 중에서 고릅니다. 개발자 콘솔로 명령어 한 줄에 조작할 수도 있습니다.

휴대폰 · 태블릿

작은 화면에서는 모바일 화면으로 바뀝니다. 아이콘 탭 옵션바, 원형 바로가기 버튼, 오른쪽 작업 패널로 손가락 하나로도 편합니다.

사용법

세 단계면 충분합니다

파일 열기

PDF · PPTX · HWP · DOCX · 이미지를 끌어다 놓거나 열기를 눌러 선택합니다. 빈 문서로 시작할 수도 있습니다.

편집 · 함께 작업

글자를 고치고, 그리고, 표와 이미지를 넣습니다. 프로젝트 관리 버튼으로 코드나 링크를 보내 함께 고칠 수도 있습니다.

저장 · 내보내기

PDF나 MPDF로 저장하고, PPTX · Word · 한글 · PNG로 내보냅니다. 인쇄와 발표 모드도 바로 쓸 수 있습니다.
