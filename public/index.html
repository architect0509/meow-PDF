새 기능

휴대폰이 발표 리모컨이 됩니다

PC와 휴대폰에 같은 계정으로 로그인하면, 휴대폰에서 ‘PC 리모컨’으로 바꿔 발표를 넘길 수 있어요. 휴대폰 화면을 누르고 있으면 그 자리가 PC 화면에 연한 레이저로 보입니다.

  • 큰 이전 · 다음 버튼으로 페이지와 애니메이션을 넘겨요
  • PC에 보이는 페이지를 휴대폰에서 미리 보며 레이저로 짚어요
  • 리모컨에서 발표 시작 · 끝내기, 발표 중에는 화면이 꺼지지 않아요

기능

문서 작업에 필요한 모든 것을 한곳에

PDF 편집부터 발표, 공동 작업, 형식 변환까지. 여러 프로그램을 오가지 않아도 됩니다.

글자 바로 수정

PDF 안의 글자를 눌러 원래 글꼴 · 크기 · 띄어쓰기 그대로 고칩니다. 스캔본도 디지털화로 고칠 수 있는 글자가 됩니다.

발표 · 애니메이션

48가지 애니메이션과 화면 전환, PPTX 애니메이션 가져오기, 레이저 포인터와 모바일 리모컨까지.

실시간 공유작업

코드나 링크 하나로 여러 사람이 같은 문서를 함께 고치고 채팅합니다.

문서 · 페이지 관리

여러 문서를 탭으로 열고 합치고, 페이지 순서 · 그룹 · 배경색을 정리합니다.

원하는 형식으로

PDF · MPDF로 저장하고 PPTX · Word · 한글 · PNG로 내보냅니다.

어디서나 · 오프라인

인터넷이 끊겨도, 휴대폰에서도, PC 프로그램에서도 작업이 이어집니다.

어디서나

인터넷이 끊겨도, 휴대폰에서도
작업은 그대로 이어집니다

Meow-PDF는 브라우저 안에서 돌아가는 문서 편집기입니다. 문서는 서버로 보내지 않고 내 기기에서 열고 고치고 저장합니다.

온라인일 때

로그인, 실시간 공유작업과 채팅, 친구 · 메일 · 알림, 페이지 번역처럼 연결이 필요한 기능까지 모두 씁니다.

오프라인일 때

한 번 열어 둔 편집기는 연결 없이도 열립니다. 파일 열기, 글자 수정, 그리기, 페이지 정리, PDF · MPDF 저장은 그대로 됩니다.

휴대폰 · 태블릿에서

컴퓨터와 같은 편집기가 작은 화면에 맞춰 바뀝니다. 손가락으로 확대하고 넘기고, 펜으로 바로 표시합니다.

다운로드

Windows · macOS · Linux 프로그램과 휴대폰 홈 화면 앱
